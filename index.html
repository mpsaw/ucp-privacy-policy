Privacy policy

Private, single-owner collection application. Version 2026-10-29.

What this application is

A private collection and portfolio application used by one person, its owner, to record and analyse their own collectibles. It is not offered to the public and has no other users. Only the configured owner account can sign in.

It is operated by that owner for personal use. It is not a business and does not sell, rent, share or advertise with anyone's data.

eBay data

The application can connect to eBay only for the owner's own eBay account, and only after the owner approves the connection on eBay's own page. It requests eBay's basic access scope and no others.

With that consent it reads the owner's own purchases as a buyer (eBay Trading API GetOrders, at most the last 90 days), only when the owner presses a button. The purchases are shown on screen once and are not stored: no order, item, price, address or message is saved.

It does not store any eBay user ID or user name, does not read other eBay users' data, does not list, bid, buy or make offers, and does not send eBay data to any artificial-intelligence tool or other service.

What is stored, and how

The owner's own eBay developer keys: the App ID and RuName as entered, and the Cert ID encrypted (AES-256-GCM).

The tokens eBay issues after consent (an access token and a refresh token), encrypted the same way. They are used only to make the reads the owner starts.

For each read: the date window requested, page, order and line counts, and an error type if it failed. No purchase content.

An audit trail of actions (for example: keys saved, connected, disconnected, and whether eBay confirmed a revocation), without keys, tokens or purchase content.

Exports and backups made from the application leave out the keys, tokens and eBay read records entirely.

How long it is kept

Keys and tokens are kept until the owner disconnects eBay, replaces or removes the keys, or the consent expires (eBay's refresh tokens last about 18 months). Disconnecting or removing deletes them from the application at once.

Read records and audit entries contain no eBay content and are kept as part of the application's history until the owner deletes them. No automatic deletion schedule has been set.

Disconnecting and deleting

In the application: Connections → eBay → Disconnect (or Remove keys). The tokens are deleted from the application first; the application then asks eBay to revoke the consent and shows eBay's answer.

At eBay: the owner can also remove this application's access in their eBay account settings.

If eBay asks for the owner's data to be deleted, the same steps apply. Because nothing from purchases is stored, there is no purchase content to delete.

Hosting and security

The application runs on Vercel and its database on Neon. Access requires the owner's sign-in; the encryption keys are held only in the hosting environment, never in the database.

When eBay returns the owner to the application after consent, eBay puts a single-use authorization code in the web address. The hosting provider's request logs may record that address. The code is exchanged immediately, expires within about five minutes and cannot be used without the owner's secret key.

Contact

This application has a single user, its owner, who controls all data in it directly through the steps above. No other contact channel has been set up.
